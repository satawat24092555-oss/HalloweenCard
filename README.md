# HalloweenCard
โค้ดนี้สร้างขึ้นเพื่อเป็นการ์ดอวยพรในวันฮาโลวีน โดยมีเสียงประกอบและ Animation เพิ่มความน่าสนใจให้กับการ์ด

## Features
- Animation เมื่อชี้ที่ไอคอนฟักทอง
- Animation ค้างคาวที่จะลอยขึ้นข้างบน
- Card คำอวยพร
- Card รูปภาพสำหรับใส่เป็นองค์ประกอบเสริม
- Sound เสียงประกอบแม่มด ค้างคาว และเสียงเปิดการ์ด

## Tools & Technologies
โค้ดนี้ใช้โปรแกรม Visual Studio Code ในการเขียน ภาษาที่ใช้ในการสร้างคือ HTML, CSS, JavaScript สำหรับการทดสอบในโทรศัพท์หรือมือถือใช้ Extension Live server ของ Ritwick Dey
